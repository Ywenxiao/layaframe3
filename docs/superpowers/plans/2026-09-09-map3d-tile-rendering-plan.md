# 3D 相机渲染 2D 地图切片 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 LayaAir 3.x 中用 3D 透视相机渲染 8×9 的 2D 地图切片，实现纯俯视轻微透视效果。

**Architecture:** Scene2D 根节点挂载 Scene3D；Scene3D 内放置透视 Camera 与空 Ground 父节点；运行时通过 `MapGrid3D` 在 Ground 下创建 72 个平躺的 Plane，每张 Plane 贴对应 `map/N.png`；地块透视与缩放完全由相机投影自动产生，脚本不做手动缩放或排序。

**Tech Stack:** LayaAir 3.x, TypeScript, ui2 模式，Laya IDE / MCP

## Global Constraints

- 每个地块世界尺寸：512×512
- 地图布局：8 列 × 9 行，编号 1~72 从下往上、从左往右
- 相机：透视投影（`orthographic = false`），高角度俯视，轻微近大远小
- 入口：`entry.main` 启动直进 `mapDemo`
- 本次不实现：建筑、角色、路径往返、寻路、相机滚动/拖拽/缩放
- 所有 UUID 需唯一：通过 `uuidgen` 或 Node `crypto.randomUUID()` 生成

## Task 3: 创建地图网格逻辑 MapGrid3D

**Files:**
- Create: `src/view/map/MapGrid3D.ts`

**Interfaces:**
- Consumes: `Laya.Sprite3D`, `Laya.MeshFilter`, `Laya.MeshRenderer`, `Laya.UnlitMaterial`, `Laya.Texture2D`, `Laya.Loader`
- Produces: `MapGrid3D.build(cfg: MapGridConfig): void`

- [x] **Step 1: 编写 MapGrid3D**

```ts
const { regClass } = Laya;

export interface MapGridConfig {
    /** 列数 */
    cols: number;
    /** 行数 */
    rows: number;
    /** 单个地块世界尺寸 */
    tileSize: number;
    /** 地块索引 1..N -> 资源路径 */
    tilePath: (index: number) => string;
    /** 父节点 */
    parent: Laya.Sprite3D;
    /** 每帧创建数量，避免卡顿 */
    batchPerFrame?: number;
}

export class MapGrid3D {
    /**
     * 在 parent 下创建 cols × rows 的地块网格。
     * 编号规则：row 从底到顶，col 从左到右；index = row * cols + col + 1。
     */
    static build(cfg: MapGridConfig): void {
        const { cols, rows, tileSize, tilePath, parent, batchPerFrame = 8 } = cfg;
        const total = cols * rows;
        const offsetX = ((cols - 1) * tileSize) / 2;
        const offsetZ = ((rows - 1) * tileSize) / 2;

        let created = 0;
        const createBatch = () => {
            const end = Math.min(created + batchPerFrame, total);
            for (let i = created; i < end; i++) {
                const row = Math.floor(i / cols);
                const col = i % cols;
                const index = i + 1;

                const x = col * tileSize - offsetX;
                const z = row * tileSize - offsetZ;

                const tile = new Laya.Sprite3D(`tile_${index.toString().padStart(2, "0")}`);
                tile.transform.localPosition = new Laya.Vector3(x, 0, z);
                // Plane 默认竖直，绕 X 转 -90° 使其平铺在 XZ 平面
                tile.transform.localRotationEuler = new Laya.Vector3(-90, 0, 0);

                const meshFilter = tile.addComponent(Laya.MeshFilter);
                meshFilter.sharedMesh = Laya.PrimitiveMesh.createPlane(tileSize, tileSize);

                const meshRenderer = tile.addComponent(Laya.MeshRenderer);
                const material = new Laya.UnlitMaterial();
                material.renderMode = Laya.UnlitMaterial.RENDERMODE_OPAQUE;
                meshRenderer.sharedMaterial = material;

                this._loadTexture(tilePath(index), material);

                parent.addChild(tile);
            }
            created = end;
            if (created < total) {
                Laya.timer.frameOnce(1, this, createBatch);
            }
        };

        createBatch();
    }

    private static _loadTexture(url: string, material: Laya.UnlitMaterial): void {
        Laya.loader.load(url, Laya.Loader.TEXTURE2D).then((tex: Laya.Texture2D) => {
            material.albedoTexture = tex;
        }).catch((err: any) => {
            console.error(`[MapGrid3D] failed to load tile texture: ${url}`, err);
        });
    }
}
```

```ts
const { regClass } = Laya;
import LogMgr from "../../core/LogMgr";
import { IView } from "../../core/UIManage";
import { MapGrid3D } from "./MapGrid3D";
import { mapDemoBase } from "./mapDemo.generated";

@regClass()
export class mapDemo extends mapDemoBase implements IView {

    onInit(): void {
        LogMgr.log("mapDemo onInit");
        this._buildMap();
    }

    onShow(...args: any[]): void {
        LogMgr.log("mapDemo onShow", args);
    }

    onHide(): void {
        LogMgr.log("mapDemo onHide");
    }

    private _buildMap(): void {
        if (!this.ground) {
            LogMgr.error("mapDemo ground node not found");
            return;
        }

        MapGrid3D.build({
            cols: 8,
            rows: 9,
            tileSize: 512,
            tilePath: (index) => `assets/cdn/map/${index}.png`,
            parent: this.ground,
            batchPerFrame: 8,
        });
    }
}
```

## 实现备注（与原计划的偏差）

原计划有几处会导致运行失败或画面错误，实现时按下面修正，已通过 `Laya_ValidateLayaAsset` 与 `tsc -p tsconfig.json` 校验：

| # | 原计划/设计 | 修正 | 原因 |
|---|---|---|---|
| 1 | 贴图路径 `assets/cdn/map/N.png` | `cdn/map/N.png` | 资源根就是 `assets/`，加载路径不带该前缀（对照 `resources/apk/version.txt`） |
| 2 | 相机 `localPosition (0, 2500, 50)` | `(0, 7600, 500)` | 地图世界尺寸 4096×4608；y=2500 时横向溢出约 2.5 倍，无法“完整显示”。7600 时在 0.50~0.75 宽高比下都能完整容纳 |
| 3 | 相机四元数 `x=+0.7071` | `x=-0.6835029051139487, w=0.7299477917637619` | 四元数 x 取正号会让相机朝 +Y（看向天空）；改为绕 X 转 -86.236°（离垂直 3.76°）才能俯视原点 |
| 4 | `farPlane: 5000` | `nearPlane: 10, farPlane: 12000` | 相机抬高后，最远地块角点距离约 8356，farPlane 5000 会裁掉远角 |
| 5 | Plane 需绕 X 转 -90° 平躺 | 不旋转 | `PrimitiveMesh.createPlane` 生成的就是 XZ 水平面（顶点 y=0、法线 (0,1,0)），再转会立起来 |
| 6 | `z = row * tileSize - offsetZ` | `z = offsetZ - row * tileSize` | 相机在 +Z 侧，屏幕上方对应 -Z；原式会把 1 号地块放到左上角。取反后 1 号在左下、72 号在右上 |
| 7 | generated 基类声明 `scene3D` | 只保留 `ground` | `Laya.Scene` 已有 `scene3D` 访问器，重复声明报 TS2610 |

其他实现细节：

- 透视强度：近端行与远端行的投影距离比约 1.036，即近处地块约大 3.6%，符合“轻微透视”
- 72 个地块共享同一份 Plane 网格，只有材质各自独立
- 未做 MCP play 目视预览（当前工具链无 play 能力），相机参数已按宽高比 0.50 / 0.562 / 0.75 数值验算，仍建议在 IDE 中目视微调
